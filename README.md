# 余时

余时是一款 Flutter 本地优先的个人项目与记录应用。它替你记住在意的事情，保留继续时需要的线索。记录不要求排期，只有主动注明日期的事项才进入今天和日历。

## 当前可用

- 此刻：随手记录、最近两个在意的方向和最近三条想法；其余内容在完整列表保留。今天的约定默认折叠。
- 快速记录：一句话保存；完整记录默认不设日期、不估算时长，其他选项折叠。可以主动选择日期，也可以取消安排并保留原内容及真实截止日。
- 有日期的事：从右上角日历进入，展示近期实际有安排的日期，可单独查找日期。周格子与周统计已移除；已有重复规则保留。
- 在意：保存长期方向、相关想法和下一步线索；每次进展追加保存，支持暂停、恢复、归档和永久删除。
- 足迹：按时间回看项目进展和做过的事，不设完成率和连续打卡。
- 今日计划图片：本地生成 PNG 预览，可保存相册或打开系统分享面板；私密任务默认不进入图片。
- 数据管理：导出完整 JSON 备份；导入前预览新增、重复和冲突，可合并或完整替换。
- 本地存储：业务数据存入 SQLite，无需账号与网络。

提醒权限和系统通知尚未接入，任务中的时间目前用于排期与展示。

## 项目结构

```text
lib/
  app_controller.dart       应用状态与操作
  data/local_repository.dart SQLite、导入与导出
  domain/                    数据模型和排期规则
  ui/                        页面、主题与功能图标
assets/
  branding/app-icon.png      应用图标源文件
  fonts/                     中文编辑风字体
docs/                        产品、流程、设计和数据契约
```

## 运行与验证

```bash
flutter pub get
flutter run
flutter analyze
flutter test
```

真机集成测试（使用临时独立数据库，不写入用户的 `yushi.sqlite`）：

```bash
flutter drive -d DEVICE_ID --driver=test_driver/device.dart --target=integration_test/device_flow_test.dart
```

测试结束后需重新安装正常入口的 release APK。不要将测试构建当作日常应用使用。

Android 安装包：

```bash
flutter build apk --release
```

## 安卓桌面小组件

设置与数据 → 添加今日待办小组件，或长按桌面空白处 → 小组件 → 余时。
提供紧凑 2×2、横向 4×2、大号 4×4 三种桌面入口，支持调整大小。正文 18sp、标题 20sp，随系统字体设置缩放；根据可用高度显示 1–8 件当天安排。不显示待办与完成数量。点击具体事项可直接完成，点击其他区域打开应用。
所有今日待办标题（含私密事项）都会显示在个人桌面上。任务变更后立即触发刷新；应用关闭后由安卓周期刷新，跨日刷新可能受省电策略延迟，可点击“刷新”重新读取当天计划。

启动首页会介绍产品理念；勾选“以后不再提示”并点击“开始今天”后，偏好保存在本地，后续启动不再显示。
