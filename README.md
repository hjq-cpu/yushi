# 余时

余时是一款 Flutter 本地优先的待办应用。围绕「待办 → 在做 → 已完成」组织事项，状态跨天保留，不再使用今天清单或每日结算。

## 当前可用（0.4.3）

- 外观：默认跟随手机系统切换浅色/深色，弹窗实时响应；分享画布固定浅色。安卓启动背景及小组件提供夜间颜色。
- 待办：首页优先展示在做与待办；搜索按需展开，项目筛选和完成记录合并为紧凑工具栏，在底部 Tab 栏上拉并松手添加事项，轻提示也支持点击，内容列表滚动不会触发。可以直接勾选完成。
- 事项详情：开始做、先放下、编辑内容与可选约定/截止日期、归档、删除。
- 完成记录：回看与撤销完成，另有保留旧记录的历史入口。
- 项目：同一批事项按项目分组，笔记与进展折叠为辅助内容。
- 日期：只展示主动注明的约定与截止日期；日期不控制事项状态。
- 分享：完整待办长图，默认隐藏私密事项，保留品牌图标和生成时间。
- 安卓小组件：显示在做与待办，点击完成同步到本地数据库。
- 数据：SQLite 本地保存；导出 v2 JSON 备份，兼容导入 v1/v2，支持合并与替换。

旧重复规则及历史记录保留，但不再自动按天产生任务。尚未接入系统提醒通知。

## 项目结构

```text
lib/
  app_controller.dart       应用状态与操作
  data/local_repository.dart SQLite、导入与导出
  domain/                    数据模型和排期规则
  ui/                        页面、主题与功能图标
assets/
  branding/app-icon.png      应用图标源文件
  fonts/                     中文编辑风字体
docs/                        产品、流程、设计和数据契约
```

## 运行与验证

```bash
flutter pub get
flutter run
flutter analyze
flutter test
```

真机集成测试（使用临时独立数据库，不写入用户的 `yushi.sqlite`）：

```bash
flutter drive -d DEVICE_ID --driver=test_driver/device.dart --target=integration_test/device_flow_test.dart
```

测试结束后需重新安装正常入口的 release APK。不要将测试构建当作日常应用使用。

Android 安装包：

```bash
flutter build apk --release
```

## 安卓桌面小组件

设置与数据 → 添加今日待办小组件，或长按桌面空白处 → 小组件 → 余时。
提供紧凑 2×2、横向 4×2、大号 4×4 三种桌面入口，支持调整大小。正文 18sp、标题 20sp，随系统字体设置缩放；根据可用高度显示 1–8 件当天安排。不显示待办与完成数量。点击具体事项可直接完成，点击其他区域打开应用。
所有今日待办标题（含私密事项）都会显示在个人桌面上。任务变更后立即触发刷新；应用关闭后由安卓周期刷新，跨日刷新可能受省电策略延迟，可点击“刷新”重新读取当天计划。

启动首页会介绍产品理念；勾选“以后不再提示”并点击“开始今天”后，偏好保存在本地，后续启动不再显示。
