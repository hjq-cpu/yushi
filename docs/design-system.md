# 余时 · 视觉与图标规范

## 1. 视觉方向

保留用户认可的编辑风大字、重点卡片和留白，用清透纸白、深墨蓝和钴蓝建立明快感。首页不改成密集的普通待办列表，也不让装饰性口号占据任务位置。

“今天做什么”必须一眼可见。任务动作是最高信息层级，哲学考量通过取舍、完成边界和允许放下来体现。

## 2. 颜色

| 名称 | 色值 | 使用 |
| --- | --- | --- |
| 纸白 | `#F8FAFF` | 页面主背景 |
| 纯白 | `#FFFFFF` | 表面、弹层 |
| 钴蓝 | `#2F5CF3` | 主操作、选中态、少量强调 |
| 墨蓝 | `#18243C` | 标题、正文、主图标 |
| 次级蓝灰 | `#5C6880` | 辅助文字、非选中图标 |
| 浅蓝 | `#EDF3FF` | 重点卡片的轻量底色 |
| 分隔线 | `#DEE5F2` | 细线和低强调边界 |
| 生长绿 | `#24775F` | 已完成、骑行与生活的辅助色 |
| 暖橙 | `#B95722` | 提醒、少量项目类别色 |

不大面积使用米黄、棕灰或低对比暖色。颜色不单独承担状态含义，必须搭配文字或图形。小字号文字的对比度目标至少为 4.5:1。

## 3. 排版与布局

- 日期和页面标题具有编辑感，但占用空间受控；首屏能看到真实任务。
- 任务、按钮、日期与说明统一使用手机系统无衬线字体，正文至少中等字重；衬线字体只用于“余时”品牌字。
- 重点任务标题通常为 24–32 px，页面标题为 30–38 px；任务较长时换行，不压缩成难读小字。
- 正文为 15–17 px，辅助文字为 12–14 px。中文使用系统清晰字体，避免细字重。
- 基础间距为 4 px 倍数，页面边距 24 px，主要内容段落间距 24–32 px。
- 重点卡片圆角 24–28 px，普通容器 16–20 px，避免所有元素都使用相同的胶囊外形。
- 留白用于区分层级；细线、色块和字重优先于厚阴影。
- 点击区域至少 44 × 44 px，即使图标本身只有 20–24 px。
- 大字体模式允许卡片增高、文字换行和页面滚动，不强制固定卡片高度。

## 4. 首页结构

1. 顶栏：品牌或日期、设置、分享今天。
2. 页面标题：今天与轻量上下文。
3. 重点卡片：具体动作、项目、时长、完成边界、一键完成。
4. 固定安排与其他今日事项：明确的任务名称和时间，不让其消失在纯装饰区域。
5. 快记入口与底部导航：今天、本周、项目。

“调整今天”“下次从哪里开始”等内容以次级操作出现。完成一件事后给予平静反馈，不使用惩罚式欠账或强制连续打卡。

## 5. 自有功能图标体系

所有功能图标通过同一组语义名称调用 Material Symbols 线性图标，不混用 Emoji 或多个图标库。应用只依赖 `AppGlyph`，后续替换图形时无需修改业务页面。

- 画板：24 × 24。
- 描边：1.8，圆端点、圆转角，默认无填充。
- 有效形状约落在 3–21 的坐标范围，允许圆形、对角线适度扩展以平衡视觉重量。
- 默认显示 24 px；紧凑辅助场景为 18–20 px，点击热区独立扩大。
- Flutter 组件统一通过 `AppIcon` 渲染，并继承当前 `IconTheme`。
- 图标默认继承当前文字颜色或 `IconTheme`。选中状态使用钴蓝；危险操作通过文字与颜色共同表达。
- 图标本体为装饰元素，交互组件负责提供完整的无障碍名称，例如“导出备份”“分享今天”。

### Flutter 使用

```dart
AppIcon(AppGlyph.today)
AppIcon(AppGlyph.share, size: 22, color: Color(0xFF2F5CF3))
```

在按钮中使用时，由父组件提供 `tooltip` 或 `Semantics(label: ...)`。不要依靠图标形状单独解释导入方式、删除后果或任务状态。

## 6. 应用图标与分享图片

应用启动图标作为品牌资产单独设计，与功能线性图标区分；遵循同一纸白、墨蓝与钴蓝色系。应在小尺寸下保留辨识度，不依赖中文小字。

分享图片沿用页面的清透编辑感：日期、今日重点和已选安排形成清晰层级。私密任务、备注和未选信息不出现在图片中；导出内容以预览为准。分享图是应用本地绘制的排版图片，不依赖在线 AI。
