# 不按天组织的待办 · 0.4.0

## 业务流程

记下标题 → 待办 → 开始做 → 在做 → 完成 → 完成记录。
待办可以直接完成；在做可以先放下返回待办；完成可以撤销返回待办。
归档是独立的隐藏状态，恢复时保留之前的待办/在做/已完成状态。删除需确认。

首页只分在做与待办，不设今日目标、日结、逾期滚动或打卡。搜索标题和备注，可按项目筛选。
项目引用同一条事项；项目笔记折叠保存，随时可写。暂停项目不隐藏事项，归档项目隐藏其开放事项。
约定日期、时间、截止日期均为可选信息，不引发状态转移。有日期入口显示所有未完成的带日期事项。
分享全部未归档的开放事项（默认排除私密）；安卓小组件显示同一范围，按可用高度展示，点击完成。小组件包含私密事项，与原设置说明一致。

## 数据和兼容

TaskItem 新增 phase：pending / doing / completed，保存到 SQLite。原 status 保留以兼容旧备份和归档。
读取缺少 phase 的数据时，一次性事项若有完成记录则迁移为 completed，其余迁移为 pending。
旧重复事项迁移为 pending，既有规则和完成记录保留，但没有每日自动重置或生成。历史入口可回看旧记录。
新增事项不依赖日期设置状态。开始、放下、日期编辑、归档均不会删除完成历史。撤销完成会移除该事项的完成记录并恢复待办。
备份输出版本为 2，允许导入 1 和 2；旧版本应用不能导入新版备份。冲突合并仍以本地版本优先，完整替换前仍自动备份。

## 验证

单元/组件测试覆盖迁移、重载、日期编辑、归档恢复、跨天完成撤销、搜索、记录入口、导入导出、项目创建归档和完整分享长图。
安卓小组件包含原生 Kotlin 逻辑，需在真机安装后进一步验证桌面交互；桌面 Flutter 测试不代表真机验证。
